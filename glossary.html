Glossary

53 essential terms spanning classical mechatronics and modern cyber-physical systems.

Actuator
Device that converts a control command into physical action (force, motion, flow, heat).
Aliasing
Distortion when sampling is too slow relative to signal bandwidth, folding high frequencies into the baseband.
Anti-windup
Technique preventing integral terms from accumulating while actuators are saturated.
Backlash
Lost motion in a mechanical transmission when reversing direction.
Bode plot
Frequency-response graph of magnitude (dB) and phase versus log frequency.
Closed-loop control
Control that uses feedback of the measured output to correct error.
Cobot
Collaborative robot designed for interaction near humans under defined safety modes.
CRC
Cyclic redundancy check — error-detecting code for digital frames.
Damping ratio
Dimensionless measure of how oscillations decay in a second-order system.
DAQ
Data acquisition — hardware/software that digitises and records signals.
Dead band
Input region producing no measurable output change.
Degree of freedom (DOF)
Independent coordinate needed to specify a mechanism configuration.
Digital twin
Virtual counterpart synchronised with a physical asset for analysis and decisions.
Disturbance
Unwanted input affecting the plant (load, ambient change, etc.).
DMA
Direct memory access — peripheral data movement without CPU byte-copying.
EtherCAT
Industrial Ethernet technology with on-the-fly processing and distributed clocks.
Fail-safe
Design property that drives the system toward a safer state under faults.
Feedforward
Control action based on measured references/disturbances before error grows.
Field-oriented control (FOC)
Vector control method for AC/BLDC machines aligning torque and flux axes.
Fuzzy logic
Rule-based reasoning using graded membership rather than strict Boolean truth.
Gain margin
Factor by which loop gain may increase before instability at the phase crossover.
Hysteresis
Path-dependent output for rising versus falling inputs.
IEC 61131-3
International standard family for PLC programming languages.
IEC 62443
Standards family for industrial automation and control system cybersecurity.
IO-Link
Point-to-point digital communication for smart sensors and actuators.
Kalman filter
Optimal estimator fusing models and noisy measurements (linear Gaussian case).
LVDT
Linear variable differential transformer — inductive position transducer.
MCU
Microcontroller integrating CPU, memory, and peripherals on one chip.
Measurand
Quantity intended to be measured.
MEMS
Micro-electromechanical systems — miniaturised mechanical devices on silicon.
Nyquist rate
Sampling-rate bound related to twice the signal bandwidth for reconstruction.
OPC UA
Open platform communications unified architecture — industrial interoperability framework.
Open-loop
Actuation without correcting from output measurement.
Phase margin
Additional phase lag tolerable at gain crossover before -180 degrees.
PID
Proportional-integral-derivative feedback controller.
Plant
Physical process or mechanism under measurement or control.
PLC
Programmable logic controller — industrial cyclic controller with rugged I/O.
PWM
Pulse-width modulation — duty-cycle encoding of an average drive signal.
Quantisation
Mapping a continuous amplitude to discrete digital levels.
ROS 2
Robot Operating System 2 — distributed robotics software framework.
RTD
Resistance temperature detector (e.g. Pt100).
Scan cycle
PLC loop of reading inputs, solving logic, and writing outputs.
Sensor fusion
Combining multiple sensors to improve state estimates.
Setpoint
Desired value of a controlled variable (reference).
SIL
Safety integrity level — measure of risk reduction for safety functions.
Strain gauge
Resistive element sensing surface strain, often in a bridge.
Time-Sensitive Networking (TSN)
Ethernet features enabling bounded-latency traffic.
TinyML
Machine learning on highly constrained edge/MCU devices.
Transfer function
Laplace-domain ratio of output to input for linear time-invariant systems.
Transducer
Device converting energy from one form to another; sensors are often transducers.
Watchdog timer
Hardware/software timer that resets a system if not serviced in time.
Wheatstone bridge
Four-element network converting small resistance changes to differential voltage.
Ziegler-Nichols
Classical empirical PID tuning approach using ultimate gain/period.
