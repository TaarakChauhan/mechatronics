Module 10 · Project Studio

Project E · ROS 2 mini stack

In simulation first, publish joint states or cmd_vel, visualise TF, and run a simple nav or pick style demo. Inspired by TU Delft Hello ROS modules and Michigan ROB 320 style ROS coursework, written here as original studio guidance.

Success criteria

  • A TF tree displays in visualisation with named frames that match your diagram.
  • A node publishes a command topic; another node or controller reacts in sim.
  • You document QoS choices for one sensor style topic.
  • A short README lists launch steps another student can follow.
Sim first Prefer Gazebo, Ignition, or other supported sims before hardware bridges. Hard realtime loops stay off the ROS graph when deadlines are tight, matching Module 8 advice.

Procedure sketch

  1. Draw frames: map, base_link, wheel or arm links, and sensor optical frame.
  2. Publish static and joint transforms until the tree looks right.
  3. Add a cmd_vel or joint trajectory publisher and a listener that logs or moves the sim robot.
  4. Run one nav or pick related tutorial path without pasting vendor prose into your report. Cite the open course you followed.
  5. Write the README with versions, launch commands, and a TF screenshot.

Worked failure · broken frames

Visualisation shows the laser floating metres away because the optical frame parent was wrong. Navigation then plans through walls. Fix: treat TF as a first class acceptance test before enabling planners.

Capstone fork After Project E you may choose a capstone: precision linear stage error budget, collaborative cell safety modes walkthrough, or Monte Carlo localisation challenge. Cite the open institutes that inspired your choice in your report (TU Delft motion systems spirit, Module 8 cobots plus ISO style reading, or Imperial Davison pattern).

Key terms

cmd_vel
Common velocity command topic for mobile bases.
TF tree
Living graph of frames; must pass visual inspection.
QoS
Delivery policies between publishers and subscribers.
Launch
Start script that brings up the node graph.
