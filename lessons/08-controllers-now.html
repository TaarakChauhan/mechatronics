Module 8 — What changed: modern systems

Controllers now

Controller silicon and software diversified. The mental model “one PLC language on one brick” is incomplete for 2026 systems.

From 8-bit to edge GPUs

STM32/ESP32-class MCUs deliver inexpensive connectivity and ample timers/ADCs. Raspberry Pi and NVIDIA Jetson-class boards bring Linux, vision, and ML to the edge — with less deterministic I/O unless carefully engineered. Soft-PLCs run IEC languages on industrial PCs beside IT stacks.

IEC 61131-3 multi-language & safety PLCs

Ladder, function block, structured text, sequential function chart — pick per problem. Safety PLCs (and safety CPUs) target SIL-rated functions with diverse channels, diagnostics, and certified runtimes separate from standard control.

Worked example — partitioning

Hard 1 kHz current loop: MCU/drive DSP. Cell sequencing: PLC. Vision pick pose: Jetson. Do not put the current loop on a non-real-time Linux process without a real-time co-processor story.

Then vs now Ladder-only culture → polyglot control + certified safety controllers + edge AI companions.

Key terms

Soft-PLC
PLC runtime on general-purpose industrial computing.
SIL
Safety integrity level (IEC 61508 family).

Toolchain reality

Expect containerised build pipelines, unit tests for logic, and hardware-in-the-loop rigs. Soft-PLCs blur IT/OT — patch management becomes part of controls engineering. Choose platforms with long-term support when machines live 15 years.

Hypervisors sometimes host real-time guests beside Windows HMIs. Timing isolation is the product; demos that ignore it fail at the customer site.

Hybrid compute patterns

Pattern A: drive + PLC + thin HMI. Pattern B: drive + soft-PLC PC + vision GPU. Pattern C: MCU product with cloud companion. Pick explicitly.

Shared memory or cyclic bus between real-time and non-real-time domains needs watchdog of data age.

License and IP strategies differ for open ROS nodes versus proprietary PLC locks — plan procurement.

Train staff on both ST/ladder and modern C++/Python stacks to avoid tribal splits.

Extended studio notes — 08 controllers now

In professional mechatronics work, the ideas in this lesson show up less as isolated definitions and more as constraints that fight each other. Partition compute so hard loops never share fate with UI garbage collection. When you write requirements, force numbers onto those constraints: sample rates, newton-metres, degrees Celsius, milliseconds of latency, millimetres of error. Vague adjectives hide trade-offs until tooling steel is already ordered.

A useful studio habit is to keep a living “assumption list” beside your block diagram. Typical assumptions include linearity, constant temperature, perfect sampling clocks, infinite actuator authority, and noise-free sensors. Assuming soft-PLC equals soft real-time without measurement is gambling. Crossing out an assumption should trigger either a model upgrade, a hardware change, or an explicit residual risk acceptance signed by someone accountable.

Commissioning is where theory meets cable trays. Expect ground loops, mis-labelled I/O, incorrect engineering-unit scales, and mechanical binding that looks like a “software bug.” Safety CPU diversity exists because systematic software faults are real. Bring an oscilloscope or drive trace tool early; bring a torque wrench and alignment dial indicator just as early. The mechatronic engineer who only debugs in an IDE will misclassify half of field faults.

Documentation is part of the control system. Record firmware hashes, gain sets, mechanical revisions, and network topologies together. Future failure analysis needs that bundle. Patch cadence for PC-based controls must be designed, not improvised. If your organisation treats documents as after-the-fact paperwork, expect to rediscover tuning constants from scratch after every staff rotation.

Finally, connect this lesson forward and backward in the course. Foundations without modern networks leave you unable to ship connected machines; modern buzzwords without foundations leave you unable to stabilise a simple loop. Networks lesson next carries the bytes these controllers exchange. Use the quizzes not as memorisation theatre but as prompts to redraw the diagrams from memory on paper — that retrieval practice builds the intuition you will need on a noisy factory floor.

Additional worked scenario

Current loop on drive DSP at 16 kHz; path planning on Jetson at 30 Hz; PLC cell logic at 20 ms. Draw three timing domains and forbid blocking RPCs from slow to fast domains without buffering.
