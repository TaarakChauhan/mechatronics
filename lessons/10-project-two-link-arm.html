Project D · Two link planar arm

Build or simulate a two link planar arm. Show forward kinematics readout, teach pendant style poses, and a simple trajectory between via points. Inspired by ETH IRM two link focus and Modern Robotics software exercises.

Success criteria

  • FK display matches a hand sketch within a stated tolerance.
  • At least two taught poses replay through a timed trajectory.
  • You identify one near singular posture and avoid it in the demo path.
  • Sim or hardware choice is documented with a rationale.
Sim first is valid If hardware is unavailable, a notebook or Modern Robotics style simulator counts. State assumptions (massless links, perfect joints) and what would change on hardware.

Procedure sketch

  1. Define link lengths and joint limits.
  2. Implement FK and a simple numeric or geometric IK for the plane.
  3. Teach three poses. Generate cubic style joint trajectories between them.
  4. Animate or run the path. Mark a singular stretch and reroute with a bent elbow.
  5. Record screenshots or a short video plus the parameter file.

Worked failure · branch flip

IK returns elbow down for one via point and elbow up for the next. The trajectory whips through a table. Fix: lock the configuration branch and seed IK from the previous joint solution.

Key terms

Teach pose
A stored joint or Cartesian target for replay.
Via point
Intermediate target on a trajectory.
Configuration branch
Elbow family chosen among multiple IK solutions.
Singularity awareness
Avoiding postures where Jacobian authority collapses.
