Module 10 · Project Studio

Project Studio mindset and safety

Institutes that teach mechatronics well force contact with reality. MIT 2.737 schedules lab checkoffs. Georgia Tech’s Mechatronics Revolution builds line followers and hexapods. Imperial College runs localisation challenges. TU Delft finishes ROS with a production line scenario. Project Studio borrows that culture for a free web course.

The studio loop

  1. Predict with a sketch and a rough calculation.
  2. Build the smallest circuit or simulation that can falsify the prediction.
  3. Measure with a plot, not only an LED.
  4. Explain mismatches (model error, noise, timing, mechanics).
  5. Only then enrich features.
Learning outcomes State how Project Studio differs from reading lessons. Use a minimum viable instrumentation habit (measure, plot, compare). Apply a safety checklist before spinning hardware. Document results so a stranger could reproduce the demo.

Safety, ESD, and lab hygiene

Power down before rewiring. Secure rotating loads. Set current limits on supplies. Know where the E stop is, even if it is your hand on the switch. Eye protection is not optional when gears can throw. Embedded projects fail safely when watchdogs and torque limits are on by default. Treat spinning shafts and pinch points with respect. Discharge awareness and grounded work habits protect both you and CMOS parts.

Safety checklist Power down before reconnection. Current limit set. Load secured. Eye protection on for rotating work. Clear E stop path. No loose hair or dangling cables near belts. Firmware torque or current caps enabled before first spin.

Documentation that counts

Record firmware hash or commit, gain set, mechanical revision, supply voltage, and a short video or plot of the acceptance test. Module 1 called documentation part of the control system. Project Studio grades you on whether a stranger could reproduce the demo.

Suggested progression

Project A Sense and display. Project B Closed loop position. Project C Line or wall follower. Project D Two link arm in sim or hardware. Project E ROS 2 mini stack in simulation first. Capstone options appear in the final project lesson of this module.

Key terms

Studio loop
Predict, build small, measure, explain, then enrich.
Acceptance test
A documented behaviour check that proves the demo.
E stop
Emergency stop path you can reach without thinking.
Current limit
Supply protection that prevents wiring faults from becoming fires.
Reproducibility
Enough recorded detail that another person can repeat the result.
