Module 9 · Robot mechanics and estimation

Sensor fusion and Kalman intuition

The glossary already lists Kalman filter. Modern mechatronic products depend on the idea behind it. Wheel encoders drift with slip. IMUs drift with bias. GPS drops near buildings. Cameras fail in glare. Fusion means trusting each sensor where it is strong and doubting it where it is weak.

Predict then update

A simple estimator carries a belief about the state (for example position and velocity). Between measurements it predicts forward with a motion model. When a measurement arrives, it updates the belief, pulling toward the measurement with a gain that depends on relative trust. If the model is confident and the sensor is noisy, the pull is gentle. If the sensor is sharp and the model is uncertain, the pull is firm.

Learning outcomes Explain why multiple imperfect sensors beat one perfect claim. Describe predict and update steps in a Kalman style estimator. Match fusion examples to mobile robots, IMU and encoder pairs, and smart sensors in Module 8. Know limits: wrong models beat fancy filters.

Covariance as humility

Uncertainty measures are not paperwork. They decide gains. Engineers who hard code infinite trust in a magnetometer indoors will fight phantom yaw forever.

Particle filters and friends

When noise is ugly or hypotheses are multimodal (kidnapped robot, multiple map matches), particle filters maintain many guesses and resample. Imperial College mobile robotics teaching builds intuition with sonar and odometry challenges. You do not need the full proof to use the vocabulary correctly in design reviews.

CPS and Module 8

Smart sensors and edge AI still need fusion discipline. A neural net that outputs a pose without uncertainty can poison a planner. Prefer pipelines that emit confidence, timeouts, and fault flags. OT security also matters: fused state is high value data. Protect it like a control setpoint.

Worked scenario · warehouse AMR

A warehouse AMR fuses wheel odometry with lidar scan matching. On slick floors, odometry overstates distance. The estimator raises odometry noise when wheel torque is high and traction estimates are poor. Lidar updates keep the map pose honest. Without that humility logic, the robot docks with growing lateral error.

Studio lab idea Simulate a 1D moving cart with noisy velocity integration and occasional noisy position pings. Implement a scalar Kalman update. Plot true position, open loop drift, and fused estimate.

Key terms

Kalman filter
A predict and update estimator that blends models with measurements using uncertainty.
Covariance
A numerical humility measure that drives how hard an update pulls.
Particle filter
Many weighted guesses; useful when hypotheses are multimodal.
Kidnapped robot
Global localisation ambiguity after a sudden unknown displacement.
Sensor fusion
Combining imperfect sensors according to where each is trustworthy.
