Module 10 · Project Studio

Project C · Line or wall follower

Build a simple mobile behaviour: follow a line with reflectance sensors, or follow a wall with ultrasonics. Add behaviour arbitration so obstacle avoidance can briefly override tracking. Inspired by Georgia Tech line following robots and Imperial practical mobile habits.

Success criteria

  • Robot completes a marked course or wall segment without operator touch.
  • You can explain the arbitration rule in one sentence.
  • A log or video shows at least one recovery after a disturbance.
  • Battery voltage and sensor thresholds are recorded.
Suggested bill of materials Differential drive base, reflectance array or ultrasonic sensor, MCU and motor drivers, and a course made from tape or a wall corner fixture.

Behaviour arbitration

Keep the architecture boring and clear. Example: if front distance is below a threshold, spin away; else run the line controller. Subsumption style layering beats a single tangled if forest. Module 8 autonomy stories start here at toy scale.

Worked failure · threshold drift

Line thresholds tuned under bright noon light fail under evening indoor LEDs. Fix: recalibrate on site, or normalise using relative channel differences, and record lighting conditions in the acceptance note.

Safety Lift test on blocks before floor runs. Cap speed. Keep cables clear of wheels. Supervise cliff edges if you use a table as a course.

Key terms

Reflectance sensor
Detects line versus floor by reflected light.
Behaviour arbitration
Priority rules among concurrent behaviours.
Subsumption
Higher priority behaviours temporarily override lower ones.
Differential drive
Left and right wheel speeds set motion.
